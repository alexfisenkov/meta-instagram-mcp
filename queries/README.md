# Архив Instagram-запросов

Эта папка хранит прикладные аналитические запросы по Instagram-аккаунту владельца локальной установки.

Публичный git хранит только этот README. Датированные папки с реальными запросами, цифрами, ссылками, скринами и выводами игнорируются, потому что это личная аналитика аккаунта.

## Правило

Один запрос = одна датированная папка:

```text
queries/YYYY-MM-DD-short-slug/
```

Внутри:

- `query.md` - исходный вопрос пользователя и дата запуска.
- `report.md` - итоговый отчёт с методикой, ограничениями, выводами и цифрами.

Все пользовательские запросы и отчёты в этой папке пишутся на русском. API-метрики, tool names и команды можно оставлять на английском, если это нужно для точности.

Если запрос тянет live Meta Graph данные, в отчёт сохраняются только отредактированные/агрегированные результаты. Не сохранять access token, app secret, OAuth code, callback URL с `code=`, cookies или сырые приватные ответы API.

## Локальный индекс

Для приватной установки можно вести `queries/local-index.md`. Этот файл игнорируется git и может ссылаться на реальные локальные папки с отчетами.

Шаблон строки:

```markdown
| YYYY-MM-DD | `YYYY-MM-DD-short-slug/` | Краткое описание запроса |
```
